# sprout-legal-site

Privacy policy, terms and account-deletion pages for **Sprout**, served by GitHub Pages at
**https://sprout-legal.mikrodev.net**.

| Path | What |
|---|---|
| `/privacy/` | Privacy policy |
| `/terms/` | Terms of use |
| `/delete-account/` | How to delete your account and data |

Home and help: https://sprout-support.mikrodev.net · Contact: support-sprout@mikrodev.net

Plain HTML and CSS with no build step. Preview locally with
`python3 -m http.server 8000`, then open http://localhost:8000.
